---
name: DocuLens first-version scope
description: User-defined boundaries for the initial DocuLens AI release.
---

For DocuLens AI's first working version, implement only PDF upload, PyMuPDF extraction, document metadata and preview, question input, document-grounded LLM answers, evidence, page/source references, and the exact unsupported-answer fallback. Do not add login, signup, payments, an admin dashboard, a user database, mobile support, or complex authentication.

**Why:** the user explicitly limited the first working version to these features.

**How to apply:** keep additional product capabilities out of the initial app; discuss them as separate follow-up work.
